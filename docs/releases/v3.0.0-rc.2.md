# v3.0.0-rc.2 — Android recording startup fix

Fixes the top-bar `RECORDING ERROR: DatabaseException ... Queries can be performed
using SQLiteDatabase query or rawQuery methods only` at `PRAGMA journal_mode=WAL`.
The pragma returns a result row; journal configuration now uses the query API
accepted by Android instead of the non-query execution API.

Install the signed APK as an update over rc.1, then fully close and reopen the app.
Do not clear local storage or uninstall to fix this error. Existing version-4
journal records and connection/USB/GPS/UI preferences are retained. No additional
schema version, reset, payload or server change is introduced by this patch.

The regression reproduces the reported error through the real mobile sqflite
client, with real SQLite storage and Android's execution restriction at the OS
boundary. After the fix, startup, append/read and reopen preserve pending records.
The existing journal and pipeline regressions also pass.

The telemetry-v2 clean-reset contract introduced in rc.1 still applies to users
upgrading from the old application/schema. The original old-format reset is not
removed by this patch. Physical Android/CAN qualification remains pending.
