# v3.0.0-rc.4 — Bluetooth LE vehicle link

The phone can now receive CAN data from the ESP32-C3 and send commands to it
over Bluetooth LE instead of a USB cable. USB stays the default; choose the link
in Config -> Connectivity -> VEHICLE LINK.

BLE mode needs matching ESP32 firmware. It must expose the Nordic UART service,
require passkey pairing, and send the same lines it writes to USB. The full spec
is in [ble-link.md](../implementation/ble-link.md). Until that firmware is
flashed, keep the app on USB.

To use BLE:
1. Switch VEHICLE LINK to BLE. Allow "Nearby devices" when Android asks.
2. Tap the scan button and select the ESP32 (`EcoArchers-...`).
3. Tap PAIR and enter the firmware passkey. The link connects and reconnects
   by itself while paired. UNPAIR removes the bond.

Install the signed APK over rc.3, then fully close and reopen the app. Do not
uninstall or clear app data. There is no journal reset and no schema or server
change. Telemetry events, timestamps, commands and acks behave as with USB, and
the existing USB port and baud settings are kept.

This build has not been tested on hardware over BLE. Before relying on it for a
session, check pairing, full-load ingest, command acks, reconnecting after going
out of range, and screen-off logging; see
[verification.md](../implementation/verification.md#ble-vehicle-link).
