# v3.0.0-rc.3 — GPS map tiles fix

Fixes the `API KEY REQUIRED / carto.com/basemaps/apikey` images in Driver's track
map and Service's finish-line editor. CARTO's keyless endpoints returned the
watermark as successful PNG responses, so ordinary HTTP error handling could not
detect that the background map was missing.

Both maps now use OpenStreetMap without requiring an API key. Attribution is
visible and links to the copyright page. Viewed tiles are cached on disk using
HTTP cache expiry; there is no prefetch or bulk download. Light mode uses the
standard map, and dark mode applies an inverted luminance filter locally. The
map style therefore differs from the previous CARTO styles.

Install the signed APK over rc.2, then fully close and reopen the app. Do not
uninstall or clear app data. The Android recording fix from rc.2 remains included;
this release introduces no additional journal reset or schema/server change.
GPS sampling, track overlays, finish-line editing and telemetry delivery keep
their existing behavior. New map regions need an internet connection.

Both original endpoints were checked and visually showed the reported watermark.
The actual replacement URL returned a street-map PNG with cache headers and was
visually verified. Physical Android/CAN qualification remains pending; confirm
both map views and light/dark themes on the phone.
